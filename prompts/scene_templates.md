# 场景生成风格模板库

> 用法：后端把 DeepSeek 抽取的画面要素（scene/elements/time_light/mood/palette）填入所选模板的槽位，
> 拼成最终 prompt 调用 CogView-3-Flash（图）或 CogVideoX-Flash（视频）。
> 全站统一从这几套模板出图，保证视觉风格一致（"AI 自动对齐已有模板"的落地）。

## T1 · 水墨写意（默认，诗词赏析配图）

```
中国传统水墨画，写意风格，{scene}，画面主体：{elements}，{time_light}，
大量留白构图，宣纸质感，淡墨晕染，远景虚化，意境{mood}，
主色调{palette}，笔触松弛克制，画面右上方留出题跋空间，杰作，高清
```

## T2 · 工笔重彩（节气主视觉）

```
中国工笔画，绢本设色，{scene}，细腻勾线，{elements}精细刻画，
{time_light}，色彩层层晕染，{palette}为主的传统矿物颜料色，
构图饱满典雅，装饰性强，博物馆藏品质感，超高细节
```

## T3 · 国潮插画（贺卡 / 分享图）

```
现代国潮插画，扁平风格，{scene}，{elements}，
明快的{palette}色块，柔和渐变，圆润造型，{mood}氛围，
构图居中对称，适合作为节日贺卡背景，画面上方留白供文字排版，矢量感，4k
```

## T4 · 实景摄影风（习俗 / 饮食）

```
纪实摄影，{scene}，{elements}，{time_light}的自然光，
浅景深，50mm 定焦视角，{mood}的生活气息，色调{palette}，
真实质感，无文字，无水印
```

## T5 · 视频 · 意境慢镜（CogVideoX-Flash 文生视频）

> 视频模板要克制：单一主体 + 单一缓慢运动，免费视频模型对复杂运动不擅长。

```
中国风意境短片，{scene}，镜头缓慢{motion}，
主体：{elements中选1项}轻微自然运动（如飘落/摇曳/涟漪），
{time_light}，色调{palette}，氛围{mood}，电影质感，慢节奏，无人物特写
```

`{motion}` 从固定池中选：推近 / 拉远 / 左移 / 上摇。

## T6 · 视频 · 图生视频（推荐路线：先 T1/T2 出图，再让画面动起来）

图生视频的 prompt 只描述"动"的部分：

```
画面整体保持原构图与风格，{elements中选1项}缓缓{动作：飘动/落下/荡漾/流动}，
光线微微流转，镜头极缓慢推近，其余元素保持稳定
```

## 通用负面提示（所有模板追加）

```
避免：文字、水印、logo、现代建筑、汽车、电线、扭曲的手、多余肢体、低质量、模糊
```
