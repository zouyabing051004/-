# 曙光坐标·5800 — 重构版（可直接使用）

> 红山—牛河梁文明交互志。本目录是一个**零依赖的静态网站**：不需要 Node、不需要 npm、不需要构建。

---

## 一、怎么用

### 1. 最快：直接打开
双击 `index.html` 即可在浏览器中使用。字体、数据、图片全部本地自带，**断网也能完整运行**。

> 少数浏览器在 `file://` 下会限制部分能力（例如「分享」按钮回落为复制网址）。若要 100% 还原，用下面任一种方式起一个本地服务。

> **把整个目录一起解压再打开。** 只把 `index.html` 单独拖出来会得到一张白页——样式、脚本、图片都在同级目录里。
> 如果只想要一个能随手带走的文件，用同级的 `曙光坐标5800_单文件版.html`：样式、脚本、字体、图片全部内嵌，放在任何位置双击都能打开（开放数据 CSV/JSON/XLSX 未内嵌，需要下载数据时请用目录版）。

### 2. 推荐：本地服务（评审现场演示用）
在本目录下执行任意一条：

```bash
python3 -m http.server 8000      # 然后访问 http://localhost:8000
npx serve .                      # 或
php -S localhost:8000
```

### 3. 上线：任意静态托管
把整个目录原样上传即可，无需任何服务器配置或路由重写：
GitHub Pages、Cloudflare Pages、Vercel、Netlify、对象存储、校内 Nginx 都可以。
放在子目录（如 `https://example.com/shuguang/`）也能正常工作——站内全部使用相对路径。

### 4. 页面地址
路由使用 hash，因此**任何一页都可以被收藏、分享、回退**，且不依赖服务器重写规则：

| 页面 | 地址 |
|---|---|
| 首页 | `index.html` |
| 公众导览（快速 3 幕） | `index.html#/tour?mode=quick` |
| 公众导览（完整 7 幕） | `index.html#/tour?mode=full` |
| 文明长卷目录 | `index.html#/chronicle` |
| 某一章 | `index.html#/chronicle/jade-and-belief` |
| 证据实验室 | `index.html#/lab` |
| 某个实验 | `index.html#/lab/tomb-matrix` |
| 开放图鉴（含检索状态） | `index.html#/atlas?q=玉&group=featured-artifacts` |
| 对象档案 | `index.html#/atlas/A002` |
| 我的考古笔记 | `index.html#/notebook` |
| 来源与方法 | `index.html#/sources` |
| 无障碍声明 | `index.html#/accessibility` |

**现场演示建议动线**：首页 → 三个文明坐标 → 首页内嵌的 66 墓互动 → `#/tour?mode=quick`（3 分钟）→ `#/lab/tomb-matrix` → `#/atlas`。

## 二、目录结构

```
index.html                 页面外壳（元信息、样式与脚本的装配清单）
styles/
  fonts.css                自托管字体子集声明
  tokens.css               ★ 设计令牌：颜色 / 字号 / 行高 / 间距 / 圆角 / 动效 / 层级
  base.css                 重置、基础排版、图像规则、焦点与跳转
  layout.css               页面骨架、页眉、页脚、区块节奏
  components.css           按钮、证据徽标、来源链接、卡片、折叠档案、表格…
  motion.css               动效与 prefers-reduced-motion
  pages/                   home / tour / chronicle / lab / atlas / notebook / sources
scripts/
  data/content.js          ★ 事实主数据（章节、导览、实验、证据卡、来源、知识检查）
  data/guides.js           ★ 公众导读文本
  data/assets.js           ★ 90 张开放图片的主数据（ID、机构、许可、署名、哈希、事实边界）
  core/dom.js              元素构建工具
  core/router.js           hash 路由
  core/store.js            学习记录（localStorage）
  components/shared.js     图像规则、证据徽标、来源链接、品牌印记
  components/chrome.js     页眉与页脚
  pages/*.js               各页面视图
  app.js                   启动、路由分发、标题与焦点管理
fonts/                     Noto Serif SC / Noto Sans SC 子集（OFL 1.1）
assets/                    图片文件（webp / avif / png），全部原色
  scene/                   氛围底图（AI 生成，已登记于 data/ai-assets.json，不进入证据层）
data/                      开放数据：CSV / JSON / XLSX / 逐张署名清单
downloads/                 开放研究工作簿
docs/                      事实来源、图片版权、AI 使用、无障碍、内容说明
```

★ 标记的三个数据文件自 V12 工程原样继承：**事实陈述、数字、口径、来源 ID 与 URL、图片身份与版权字段均未被改动**，只把图片路径从 `/media/assets/…` 规范成站内相对路径 `assets/…`。

### 想改内容？
- 改文案 / 事实 → `scripts/data/content.js`、`scripts/data/guides.js`
- 改图片档案 → `scripts/data/assets.js`
- 改配色、字号、间距、动效 → **只改 `styles/tokens.css`**，全站自动跟随
- 改某一页版式 → `styles/pages/<页面>.css` + `scripts/pages/<页面>.js`

> 若新增了字体子集里没有的汉字，浏览器会自动回落到系统宋体／黑体（仍然可读）。需要完全一致的排版时，用 `fonttools` 按新文本重新生成 `fonts/` 下的两个 woff2 即可。

## 三、这次重构做了什么

### 1. 首页：从「全站目录」改成「文化故事入口」
六个模块一条主线，纵向长度较原版明显收短：

`序厅 → 三个文明坐标（5800 / 09 / 2026）→ 证据实验室 → 三章长卷预览 → 对象之证 → 结语`

- **序厅**只保留一个视觉主角、一个主标题、一句主张、两个入口、一句素材身份说明。删掉了重复的巨型 `5800`、右上角幽灵数字、经纬度装饰线，以及第三、第四入口。
- **三个文明坐标**是新增的品牌识别结构：三个数字各带一句结论与一个「进入证据」入口，结论文本直接取自事实主数据。
- **证据实验室提前**，并在首页内嵌一个**真实可操作**的 66 墓互动——下滑一屏就能发现这不是普通宣传页。
- 九章只预览 3 章，图鉴只展示 5 件，其余通过入口进入。

### 2. 视觉系统：玉礼曙光 / DAWN OF RITUAL
- **色彩**：象牙纸 `#F3EEE4` / 墨黑 `#171A17` / 红山玉青 `#44786B` / 朱砂土红 `#A44A35` / 曙光金 `#C98A47` / 石灰褐 `#81776B`，约 70 / 15 / 7 / 5 / 3 的比例。
- **深色成为一种模式切换**：只有序厅与证据实验室使用深色沉浸；长卷、图鉴、笔记、来源页回到浅色博物馆编辑界面。
- **品牌印记重做**：外双环＝玉璧与圆形礼制秩序，水平线＝考古地层，升起的半弧＝曙光，地层线上的点＝牛河梁坐标。几何抽象，不描摹任何馆藏器物。
- 建立了完整的 **Design Tokens**，删除了为单个卡片写一次性数值、`nth-child` 人为错位与无意义位移的做法。

### 2b. 图像：一张图要么是「一件器物」，要么是「一张照片」
这是本次美化里最主要的一处判断，它同时解决了视觉问题和事实问题：

| 身份 | 版式 | 表现 |
|---|---|---|
| 器物 / 馆藏对象 | **陈列台** | 按原始比例呈现，不套底板方框，底边落在同一条陈列基线上 |
| 地景 / 方法 / 研究模型 | **画框** | 作为一张照片满幅呈现在等高的框内 |

- 竖幅器物过去只能填满方框的一半，剩下的白底读起来像「图没加载」；现在四周的留白是展台，形状各异的器物落在同一条线上，一行之内基线必然对齐。
- 同一行中陈列台与画框**等高**，图注基线因此不会错位。
- 尺寸太小撑不起陈列台的缩略图（证据卡、同组对象、比较轨道）改用居中软垫，不画那条线。
- hover 反馈也按角色分配：有实体面的卡片微微抬起；陈列台上的器物则是「被拿近一点看」——器物轻抬、基线转为朱砂。

### 2c. 版面与节奏
- **纵向节奏分三级**（叙事 136px / 常规 104px / 同族相邻 76px），不再是全站一律 120px 的等距堆叠。
- **分区标题＝编辑式抬头带**：顶边细线定住栏目，标题在左、导语在右，中间的空白因此属于版面结构，而不是「没排满」。
- 中文行长改用 `em` 计量（1 个汉字 ≈ 1em）。此前用 `ch`（拉丁「0」的宽度）会把中文行长算成一半，正文与导语的断行都因此偏窄。
- 文明长卷目录收窄成一条 1080px 的阅读柱，章节标题放大到 31px，图片左右交替但**宽度一致**，中缝不再空一大片。
- 页面静止时即完整可读：删除了「先隐藏、滚动到才淡入」的进场动画，内容永远不等动效。

### 3. 排版：公众可读信息不再有小于 12px 的字
| 层级 | 尺寸 |
|---|---|
| 正文 | 17px（导语 18–20px），行高 1.75 |
| 导航中文 | 15px |
| 元数据 | 13px（编号、许可等次级字段最低 12px） |
| H1 | 桌面 `clamp(46px, 6.2vw, 92px)` |
| H2 | `clamp(32px, 4.4vw, 58px)` |

中文是唯一视觉主语言；英文只保留在品牌副标与极少数栏目辅助里，首页英文微标签较原版减少约七成。资产 ID、证据等级、版权字段仍然完整保留，但下沉到对象详情与来源页。

### 4. 文物图片恢复原色
删除了原版全站的 `saturate(.6)` 一类统一降饱和滤镜。**真实文物、馆藏、遗址与方法照片一律原色显示**；只有序厅氛围图允许一次极轻的明度压暗，用来保证叠字对比度。器物图按 `contain` 完整显示，不裁掉关键形态。

### 5. 页面节奏不再只有一种模板
原版几乎所有模块都是「大图 → 深色遮罩 → 左下角小标签」。现在建立了四种节奏：
电影式序厅｜浅色编辑排版（长卷、来源）｜对象型陈列（图鉴、对象之证）｜深色交互实验（实验室）。

### 6. 工程结构
原版 `app/page.tsx`（约 790 行 / 82 KB）与 `app/globals.css`（约 1080 行 / 109 KB）两个巨型文件，已拆成
7 个样式模块 + 7 个页面样式 + 13 个脚本模块，并抽出统一的设计令牌与共用组件。

- 320–390px 移动端回流
- 页面中不含学校、院系、姓名、指导教师等参赛身份信息

**报告导出版式已重做**：不再复用首页序厅图，改为与网站品牌一致的独立田野札记版式（纸底横格、朱砂装订线、玉璧坐标印记、二维码）。

## 五、无障碍与响应式

- 目标 WCAG 2.2 AA。正文、元数据与状态色均按浅底/深底两套分别校验对比度。
- 所有可操作控件最小 44px，焦点框 3px（深色区改用曙光金）。路由切换后焦点移到新页面主标题供读屏播报，该容器本身不画焦点框。
- 数据图形都配有文字等价内容（如 66 墓矩阵附「分类 / 数量 / 口径」表格）。
- 完整支持系统「减少动态效果」偏好；进场动效带兜底，任何异常下内容都不会被动效隐藏。
- 已在 1440 / 1280 / 1024 / 820 / 768 / 390 / 375 / 320px 逐页检查，无横向滚动。

## 七、V13.1 这一轮改了什么

### 1. 参考上传截图后的版面与配色调整
- 序厅改为 45/55 分栏，竖屏另出一版 `hero-dawn-portrait.webp`；层级固定为 **站名 → 主张 → 导语 → 两个入口 → 素材身份说明**。
- 首页「对象之证」区块借素材包的展台顶光做成展厅照明（`assets/scene/stage-light.webp`），图片只作氛围底光，上压纸色罩，正文实际底色仍在 `--paper-bright` 附近。
- 「来源与方法」的 20 张证据卡由 20 个描边方框改为**账册式条目**：栏间只留一条发丝线，靠图、标题与朱线自成单元。该页的框体容器数由 53 降到 33。
- 新增无障碍曙金 `--dawn-ink: #87631B`，供浅底上的小字使用（`--dawn-deep` 仍用于大字）。

### 2. 外部 AI 素材包：逐张核查后分三类处理
采用 6 张纯氛围底图；剔除 6 张（错误地图、会伪造空间／数量关系的图谱与矩阵、把器物画进层位的地层图、两张祥云与金线母题）；把其中两张必要的示意图改为**站内自绘**。完整核查记录见 `docs/AI_ASSISTANCE.md` 与 `data/ai-assets.json`（新增 `AI-006` 与 `AI-REJ-001` 两条）。

### 3. 两张自绘示意图
| 组件 | 位置 | 说明 |
|---|---|---|
| `ui.liaoxiSchematic()`（SVG） | 长卷第 01 章 | 只表达相对方位，不画边界、不标距离、不设比例尺 |

### 4. 单文件版修好了一处静默失效
