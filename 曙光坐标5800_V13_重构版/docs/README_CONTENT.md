# 内容发布手册

更新日期：2026-07-15

本手册是《曙光坐标·5800：红山—牛河梁文明交互志》的编辑入口，适用于首页、文明长卷、证据实验室、图鉴、来源页及答辩演示。

## 网站定位

面向大众，把考古材料转译为可理解、可核验的文明证据链。网站不是“文物壁纸库”，也不替用户给出超出证据的唯一答案。

固定非官方声明：

> 本网站为文化设计竞赛与公众教育性质的独立数字作品，非牛河梁遗址博物馆、辽宁省文化和旅游厅、国家文物局或 UNESCO 官方网站，不代表相关机构立场。

该声明应在页脚、关于页和来源页清晰可见；不得使用“官方数字馆”“联合出品”“授权发布”等未经证明的措辞。

## 四份发布规范

- [无障碍声明与验收规范](./ACCESSIBILITY.md)：WCAG 2.2 AA 目标、键盘/屏幕阅读器/动效/替代内容。
- [AI 辅助创作披露](./AI_ASSISTANCE.md)：研究性复原、设计示意、AI 生成视觉的边界与登记。
- [事实来源与口径](./FACT_SOURCES.md)：事实条目、来源、冲突、限定词和更正流程。
- [图片与地图权利](./IMAGE_RIGHTS.md)：开放许可、署名、事实边界与阻断条件。

## 受众与三层阅读

每个主题默认提供三层深度：

1. **一句话结论**：普通用户 10 秒内理解，不使用未经解释的术语。
2. **证据与语境**：展示数据、遗迹关系、研究方法与认识变化。
3. **来源与边界**：列出来源、核验日期、限定词、争议和未知。

不强迫用户阅读长文才理解操作，也不把全部信息压成营销口号。互动应帮助比较证据，而不是只增加点击次数。

## 语气与命名

- 语气克制、准确、可亲近；优先用“目前资料显示”“研究认为”“提示”“可能”“尚待验证”。
- 避免“震惊世界”“中华第一”“神秘王国”“史前帝国”“金字塔”等猎奇、绝对或未经证实的说法。
- 首次出现使用全称，随后才可用简称；人物、器物、地点和机构名称以来源登记为准。
- “UNESCO 世界遗产预备名单 Ref.5804”不能简写成“世界遗产”或“申遗成功”。
- “5800”是叙事坐标和阶段框架，不是所有遗迹的统一建成年份。
- 比较标本必须写明馆藏/来源和“未证明为牛河梁出土”；通用考古图片必须写明不是牛河梁现场。

## 中文排版与数字

- 使用规范中文全角标点；中文与拉丁字母/阿拉伯数字之间的空格由统一排版规则控制，不逐页随意处理。
- 年代、范围和单位保持同一口径，例如“距今约 5800—5200 年”“64.61 米”“1000 平方米”；范围使用连接号，不用波浪号制造含混。
- 数字旁必须给出对象和范围，避免只展示“66”“518”“145”等脱离语境的大数字。
- 正文不使用全大写英文、连续感叹号、表情符号和大段居中排版。
- 题名可有展览感，长文仍以可阅读的字号、行长和行高为先；图片中的文字不能承担唯一信息。

## 内容组件最低要求

| 组件 | 必须包含 |
| --- | --- |
| 事实卡 | 安全文案、对象/范围、来源 ID、核验日期、证据状态 |
| 器物卡 | 题名、文化/年代、馆藏或来源、出土边界、作者/许可、替代文本 |
| 遗址图 | 比例/方向、数据来源、设计示意标签、不确定性、无障碍长描述 |
| 研究性复原 | 事实依据、推断与未知、AI/人工制作披露、非实景说明 |
| 数字图表 | 分母/样本、单位、统计口径、数据表替代、来源 |
| 历史时间线 | 当时口径、当前认识、发布日期，不用新结论抹去旧认识 |

## 发布流程

1. 编辑从 `fact_claims.csv` 选择条目，不先写宣传文案再找依据。
2. 事实复核人检查来源、范围、限定词和冲突表。
3. 图片编辑检查资产 ID、许可、署名、事实边界和文件完整性。
4. 若使用 AI，登记模型、提示词摘要、依据、人工修改与页面标签。
5. 前端完成语义结构、替代文本、键盘、对比度、减少动态效果和移动端回流。
6. 在真实设备上完成关键路径测试，并保存截图、版本号和缺陷记录。
7. 内容、事实、权利、AI 与无障碍五位责任人（可由同一团队成员兼任）完成签署后发布。

## 发布门禁清单

- [ ] 非官方声明在页脚、关于页与来源页可见。
- [ ] 所有重要主张可追溯到 `claim_id` 和 `source_id`，限定词未丢失。
- [ ] UNESCO 身份、第十三地点、年代、墓葬/玉器和调查网格口径无误。
- [ ] 没有把比较标本、区域地貌或通用方法图写成牛河梁出土/实景。
- [ ] 每项图片有许可、署名、来源、事实边界和可访问替代文本。
- [ ] AI 图在首次出现处标为“研究性复原”“设计示意”或“AI生成视觉”。
- [ ] 研究性复原明确证据、推断、未知和“不代表遗址原貌”。
- [ ] WCAG 2.2 AA 目标测试已记录；未通过项已列为公开限制并有替代方案。
- [ ] 3D、全景、拖拽和动效均有静态、文字、按钮或键盘替代。
- [ ] 发布包不含敏感坐标、未授权图版、机构徽标、零字节或损坏文件。
