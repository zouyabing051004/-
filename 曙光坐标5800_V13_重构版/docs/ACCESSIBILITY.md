# 无障碍声明与验收规范

更新日期：2026-07-15
适用范围：《曙光坐标·5800：红山—牛河梁文明交互志》网页应用

## 项目身份与当前状态

本网站是面向公众教育与文化设计竞赛的独立数字作品，不是牛河梁遗址博物馆、辽宁省文化和旅游厅、国家文物局或 UNESCO 的官方网站，也不代表上述机构立场或获得其背书。

本项目以 [WCAG 2.2](https://www.w3.org/TR/WCAG22/) **AA 级**为发布目标。除非完成本文件所列的人工与自动化测试，不得对外宣称“完全符合 WCAG 2.2 AA”。当前发布文案应写作：

> 本网站以 WCAG 2.2 AA 级为无障碍设计与测试目标。若您在使用中遇到障碍，请通过项目反馈渠道告知页面、设备、浏览器及问题描述；我们将提供可访问的替代内容并持续修正。

## 基础要求

### 结构与导航

- 每页有唯一、明确的 `h1`，标题层级不跳级；地标使用 `header`、`nav`、`main`、`aside`、`footer`。
- 页面开头提供“跳到主要内容”链接；所有核心功能只用键盘即可完成。
- 键盘焦点顺序与视觉阅读顺序一致，焦点样式始终可见，不被粘性导航、对话框或动画遮挡。
- 路由切换后更新页面标题，并将焦点移至新页面主标题或主要内容起点。
- 链接和按钮名称须描述目的，避免仅写“更多”“查看”或依赖图标含义。
- 弹窗、抽屉和全屏图鉴支持 `Esc` 关闭，打开时正确管理焦点，关闭后焦点返回触发控件。

### 文本、色彩与缩放

- 正文文字与背景的对比度不低于 4.5:1；大号文字不低于 3:1；交互控件和焦点指示器不低于 3:1。
- 不以颜色作为证据等级、选中状态、错误或时间阶段的唯一提示；同时提供文字、形状或图例。
- 页面在 200% 缩放下保持可读可操作，并在 320 CSS 像素宽度下无须横向滚动；地图、时间轴等确有二维含义的组件可局部滚动。
- 正文允许浏览器字号和行距覆盖；不得用图片承载必要文字、数字、来源或图例。
- 中文正文建议保持 1.6—1.9 倍行高，段落宽度控制在适宜阅读范围，不以极细字重承载长文。

### 图片、图表与媒体

- 信息图片必须有与页面语境相符的替代文本；纯装饰图片使用空替代文本 `alt=""`。
- 替代文本不得只重复题名，应说明图像为何出现在此处。复杂地图、墓葬矩阵、台基关系图另附可展开的长描述或数据表。
- 图像题注、作者、许可和事实边界属于正文信息，不能只塞入 `alt`；`alt` 也不能代替署名。
- 视频必须有同步字幕；有重要环境声或视觉信息时提供音频描述或等效文字稿。
- 自动播放的声音默认关闭。超过 5 秒的移动、闪烁或自动更新内容必须可暂停、停止或隐藏。
- 不制作每秒三次以上闪烁的内容。

### 动效、3D 与交互

- 尊重 `prefers-reduced-motion: reduce`：停用视差、连续漂浮、镜头推拉和非必要转场，保留不依赖运动的状态反馈。
- 拖拽、旋转、缩放等手势必须有按钮或键盘替代；触控目标至少为 44 × 44 CSS 像素，或满足等效间距要求。
- 3D、全景、AR 和时间轴只能作为增强层，必须同时提供静态图片、文字说明和可访问的数据表。
- 任何“证据擦拭”“前后对比”交互，都要有不需精细指针操作的切换按钮，并向辅助技术播报当前状态。
- 进度、筛选结果和错误使用可感知的状态信息；不让屏幕阅读器用户等待无提示的动画结束。

## 发布前测试矩阵

发布负责人应保存测试日期、版本号、设备与缺陷记录。最低测试范围：

| 场景 | 最低检查 |
| --- | --- |
| 键盘 | Chrome/Edge：`Tab`、`Shift+Tab`、方向键、`Enter`、`Space`、`Esc` 完成全部主流程 |
| 屏幕阅读器 | Windows Narrator 或 NVDA + Chrome/Edge；核对标题、地标、名称、状态、表单提示 |
| 移动端辅助功能 | iOS VoiceOver 或 Android TalkBack 至少完成首页、长卷、图鉴、来源四条路径 |
| 缩放与回流 | 200% 缩放、320 CSS 像素宽度、横竖屏切换，不丢内容和功能 |
| 颜色与对比 | 正文、按钮、图例、焦点、禁用态逐项测量；灰阶下仍可理解 |
| 动效 | 系统“减少动态效果”开启后，无眩晕性转场且信息不缺失 |
| 媒体替代 | 图片替代文本、复杂图长描述、视频字幕/文字稿、3D 静态替代均可访问 |

## 已知限制与反馈处理

若发布时仍有不能立即解决的限制，必须在公开声明中列出受影响页面、问题、替代访问方式和预计修正版本，不得以“使用无障碍工具栏”替代原生修复。

反馈记录至少包含：页面地址、设备与系统、浏览器、辅助技术、问题描述、可复现步骤和联系方式。收到反馈后优先提供纯文本、静态图、表格或人工说明等替代内容。
