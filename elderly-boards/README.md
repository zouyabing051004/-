## 图纸解读（从 CAD 矢量反算）
- 比例标定：楼梯踏步 270 mm、开间 3.3 m ⇒ **1 pt ≈ 0.1 m**（面积、尺寸均由此推算，为约数）。
- 南侧 8 间 3.3 m 开间 × 7.5 m 进深单元（各含 1.7×2.9 m 卫生间，镜像成对）；中廊约 1.8 m；东端 6.6 m 大厅；
  沿 40° 折出 4 间转角翼（自带 1.9 m 走廊）；两层核心筒相同（2 楼梯 + 3 电梯）。
- 二层 CAD 相对一层平移 (6.4, 39.1) pt 对齐后共用一套坐标。

## 设计定位（假设，可调整）
养老 · 温馨 · 适老。一层 = 公共服务与日间照料（接待、医务、康复、理疗、谈话、食堂、文娱），二层 = 12 间单人居室 + 日光起居厅 + 护理站 / 助浴。
部分房间用途由开间模数与设备管井位置推断，图纸未标注功能。

## 重新生成
```bash
./build_all.sh      # 需要 python3、node、chromium（playwright）
```
源码：`src/cad.py`（CAD 提取）· `model.py / plans.py`（几何与功能策划）· `render.py`（彩平/分析叠加层）· `furn.py`（家具符号）· `illus.py / scenes.py`（立面插画）· `board1-3.py`（排版）。

## 说明
- 无法生成真实感渲染图：展板中的“效果图”为矢量立面 / 轴测插画，可在 `board*.py` 中替换为自己的渲染图。
- JGJ 450-2018、GB 50763-2012 仅作参考，数值为设计取值，深化阶段需按现行规范与专业灯光、暖通复核。
