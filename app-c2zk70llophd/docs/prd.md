# 需求文档

## 1. 应用概述

### 1.1 应用名称

禾间识岁——二十四节气儿童互动学习平台

### 1.2 应用描述

面向3-8岁儿童及家长的二十四节气学习网页平台。以低饱和马卡龙色系+绘本插画风格呈现节气知识、民俗饮食、诗词文化，提供AI智能对话、实景社区分享、积分排行等功能。采用封闭知识库确保内容安全，支持幼儿模式（3-5岁）与学龄模式（6-8岁）分级展示。支持桌面端（平板/宽屏）与手机端（375px-430px宽度）响应式适配。技术栈：React + TypeScript + Tailwind + shadcn/ui + Supabase。

## 2. 用户与使用场景

### 2.1 目标用户

- 主要用户：3-8岁儿童
- 辅助用户：家长、教师

### 2.2 核心使用场景

- 儿童自主学习二十四节气知识
- 课堂教学辅助工具
- 家庭亲子互动学习
- 节气实景照片分享与社区互动

### 3.2 全站视觉设计规范

## 4. 业务规则与逻辑

### 4.1 封闭知识库规则

- 所有内容基于预设的二十四节气知识库
- 知识库内容经过审核，确保无广告、无不良信息
- AI生成内容必须在知识库范围内，不得引用外部未验证信息

### 4.2 AI对话安全过滤规则

- 儿童输入内容需经过敏感词过滤
- AI返回内容需经过二次审核，确保符合儿童内容标准
- 禁止返回暴力、色情、政治敏感等不良信息

### 4.3 节气倒计时计算规则

- 根据当前日期（2026年6月21日）计算距离下一个节气的天数
- 下一个节气为夏至（2026年6月21日），倒计时0天

### 4.4 AI配图生成规则

- 所有配图使用图片生成与编辑技能生成
- 配图风格统一为绘本插画风，色彩明亮柔和
- 使用低饱和马卡龙色系（浅绿 #A8D5B5、奶蓝 #B8D4E8、暖橙 #F5C87A、粉白 #FFF8F0）
- 配图内容与节气主题强相关

### 4.5 语音朗读规则

- 使用MiniMax语音合成技能将诗词文本转换为语音
- 语音风格分为童声（3-5岁）、温柔女声（6-8岁）
- 背景音乐使用轻古风纯音乐，音量低于20%
- 语速适中，适配儿童听觉习惯
- 支持播放/暂停/重播控制

### 4.6 内容分级规则

- 幼儿模式（3-5岁）：仅展示绘本插画+短句解说+纯朗诵
- 学龄模式（6-8岁）：增加实景图+字词注解+简易科普
- 用户可通过开关切换模式

### 4.7 思维导图交互规则

- 中心节点显示节气名称
- 各主题作为分支节点，点击后向外发散展开具体内容
- 民俗饮食分支展开后显示北方和南方子节点
- 点击子节点展示具体内容

### 4.8 实景社区积分规则

- 用户每次上传照片+1积分
- 积分数据存储至Supabase后端
- 积分排行页按积分从高到低排序展示

### 4.9 响应式适配规则

- 桌面端（平板/宽屏）：保持原有布局
- 手机端（375px-430px宽度）：
  + 顶部导航收起为汉堡菜单
  + 底部Tab导航固定在页面底部
  + 侧边栏自动收起
  + 卡片纵向堆叠
  + 字体缩小至适配手机屏幕
  + 功能快捷卡2列网格布局
  + 所有页面内容无横向溢出
  + 所有功能可正常操作
  + 保持森林背景+木质卡片整体视觉风格

## 5. 异常与边界情况

| 场景 | 处理方式 |
| --- | --- |
| 儿童输入无关内容 | AI智能体提示「请输入与节气相关的问题」 |
| 儿童输入敏感词 | 过滤敏感词，提示「请使用文明用语」 |
| AI生成内容超时 | 显示「正在思考中，请稍候」，超过10秒提示「网络不稳定，请重试」 |
| 知识卡片生成失败 | 提示「生成失败，请重试」 |
| 语音合成失败 | 提示「语音生成失败，请重试」 |
| 语音播放中断 | 支持重新播放 |
| 照片上传失败 | 提示「上传失败，请检查网络或重试」 |
| 照片上传时未填写城市/节气标签 | 提示「请填写完整信息后上传」 |
| 积分数据加载失败 | 提示「数据加载失败，请刷新页面」 |
| IP定位失败 | 默认展示北京天气 |
| 天气数据获取失败 | 提示「天气数据暂时无法获取」 |
| 思维导图节点加载失败 | 提示「内容加载失败，请重试」 |
| 实景图片加载失败 | 显示占位图，提示「图片加载失败」 |
| 手机端页面横向溢出 | 检查并修复布局，确保所有内容在375px宽度下正常显示 |
