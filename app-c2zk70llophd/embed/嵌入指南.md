# 「知节」智能体嵌入指南

把传统文化智能体作为**悬浮聊天球**嵌入 https://app-c2zk70llophd.appmiaoda.com ——页面右下角出现 🌾，点开即聊。

## 挂件的三级能力（同一段代码，自动升级，无需改动）

| 模式 | 前提 | 对话大脑 | 知识库 |
|---|---|---|---|
| ③ 今天就能用 | 无需任何配置 | 文心（已部署的 multimodal-chat） | 挂件内置：精选 20 首（人工校准三重锚定）+ 24 节气表 |
| ② 数据库就绪 | 执行迁移 00005 + 00006 | 文心 | **Supabase 数据库 500 首**（search_culture_poems 检索） |
| ① 完全体 | 再配 DEEPSEEK_API_KEY 并部署 culture-agent-chat | **DeepSeek** | 数据库 500 首（服务端检索，提示词只有一份权威实现） |

配画/小视频在三种模式下都可用（走已部署的 MiniMax 文生图 + 可灵图生视频）。朗读优先 MiniMax 儿童音色，失败自动降级浏览器语音。

## 方式 A：一键粘贴（推荐，5 分钟）

1. 打开 `embed/一键嵌入代码.html`，**全选复制**全部内容（约 44KB，含 `<script>` 标签）；
2. 在秒哒编辑器中，给页面添加一个「自定义代码 / HTML」组件（通常在组件面板的"高级"分类里；若你的版本不支持，用方式 C）；
3. 粘贴、保存、发布。刷新网站，右下角出现 🌾 聊天球。

> 想默认英文界面？在粘贴内容的 `<script>` 起始处先加一行：
> `window.ZHIJIE_CONFIG = { language: "en" };`

## 方式 B：托管为一行引用（更干净）

把 `embed/zhijie-widget.bundle.js` 上传到你自己的 Supabase 公开存储桶，得到固定 URL 后只需嵌一行。

在你自己的电脑上执行（把 `<ANON_KEY>` 换成 `.env` 里的 VITE_SUPABASE_ANON_KEY）：

```bash
curl -X POST "https://backend.appmiaoda.com/projects/supabase320478069733244928/storage/v1/object/generated-audio/widget/zhijie-widget.bundle.js" \
  -H "Authorization: Bearer <ANON_KEY>" -H "apikey: <ANON_KEY>" \
  -H "Content-Type: application/javascript" \
  --data-binary @embed/zhijie-widget.bundle.js
```

然后在秒哒自定义组件里只放这一行：

```html
<script src="https://backend.appmiaoda.com/projects/supabase320478069733244928/storage/v1/object/public/generated-audio/widget/zhijie-widget.bundle.js"></script>
```

> 注：该桶的安全策略是"匿名可新增、不可覆盖"，文件一经上传不可被他人篡改；更新挂件时换一个文件名（如 v2）再改引用地址即可。

## 方式 C：iframe 兜底

若秒哒不允许自定义脚本：把仓库里 `examples/widget.html` 部署到任意静态托管（或直接用效果演示页），在秒哒加"网页嵌入/iframe"组件指向它。

## 升级到模式 ②：数据库知识库（500 首）

在 Supabase SQL 编辑器（秒哒后台 → 数据库）依次执行：

1. `supabase/migrations/00005_create_culture_poems.sql` —— 建表 `culture_poems` + 只读策略 + 检索函数 `search_culture_poems`
2. `supabase/migrations/00006_seed_culture_poems.sql` —— 灌入 500 首（20 精选 + 305 唐诗 + 149 宋词 + 26 元曲）

验证：`SELECT title, author FROM search_culture_poems('教我读静夜思', 3);` 应返回《静夜思》。

执行完后**站内页面和挂件都自动**用上数据库知识库，无需改代码。

## 升级到模式 ①：DeepSeek 完全体

1. https://platform.deepseek.com 注册 → 创建 API Key（新账号送 500 万 token）；
2. Supabase 后台 → Edge Functions → 环境变量，添加 `DEEPSEEK_API_KEY`；
3. 部署 `supabase/functions/culture-agent-chat`（与站内其他函数同样方式）；同时部署 `deepseek-chat`（站内 `/culture` 页面使用）。

挂件探测到 culture-agent-chat 可用后自动切换，检索与人设提示词统一收敛到服务端。

## 安全与合规要点

- 挂件里只包含 **anon key**（本来就随前端公开），所有敏感 Key 均在服务端环境变量；
- 知识库表开启 RLS，匿名只读；
- 挂件不采集任何个人信息，记忆（语言偏好/最近话题）只存访客本机 localStorage，符合面向国际儿童的 COPPA/GDPR-K 取向；
- AI 生成的图片视频带"AI 生成"标注。
